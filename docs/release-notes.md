Windows 10/11 x64 下载测速工具，下载 **SpeedTest.exe** 后直接运行，无需安装 Python。

- 实时、平均和峰值速度，累计流量、运行时间与 60 秒曲线。
- 可调并发连接、自定义下载地址、手动停止与定时停止。
- 内置 Apple CDN、Hugging Face Models、GitHub Releases、Custom 测速集合，支持一键恢复默认地址。
- 支持 HTTP、HTTPS、SOCKS5 代理及账号认证。
- 配置自动保存，代理密码仅在当前会话使用。
- 修复“测速”和“设置”标签在选中状态下宽度不一致的问题。
- GitHub Releases 集合更新为 8 个单文件超过 1 GiB 的固定版本下载地址。
- 修改测速地址后会保留原集合，并在保存后重新读取配置验证结果。
- 切换测速集合时保留本次会话中各集合已编辑的地址，只有恢复集合默认才覆盖它们。
- 将测速集合改为按钮选择，并将恢复集合默认按钮移至下载地址标题行右侧。
- 增加可展开的线程明细，实时显示每个线程的状态、速度、累计流量和实际地址。
- 线程明细移除横向滚动条，地址改为自动换行，并支持点击字段名称排序。

`SHA256SUMS.txt` 提供 EXE 的 SHA-256 校验值。
